### [FIXED] Train-only `MIN_GAMES_PER_SEASON=6` filter hurt cold-start prediction — relaxed to 1 per-position for RB/WR/TE
- **File(s):** [src/shared/position_config.py](../../src/shared/position_config.py) (new general `min_games_per_season` field), [src/shared/position_pipeline.py](../../src/shared/position_pipeline.py) (`build_pipeline_config` maps it, resolving None→global so the cfg/cache value is concrete), [src/shared/pipeline.py](../../src/shared/pipeline.py) (`_prepare_position_data_uncached` reads the cfg value), [src/shared/feature_cache.py](../../src/shared/feature_cache.py) (threshold in the config fingerprint), [src/rb/config.py](../../src/rb/config.py)/[wr](../../src/wr/config.py)/[te](../../src/te/config.py) (=1); filter replications in [covariate_shift.py](../../src/analysis/covariate_shift.py) + [wr/benchmark_ridge_variants.py](../../src/wr/benchmark_ridge_variants.py). Harness + finding: PR #638; productionization: PR #656.
- **What:** the games-per-season floor was applied to TRAIN only (val/test kept every row), so models trained only on ≥6-game players but were scored on everyone — a self-inflicted train→test covariate shift on the low-volume/cold-start subgroup. Bare global constant in [src/config.py](../../src/config.py), no documented rationale.
- **Fix:** per-position `min_games_per_season` knob (None → global fallback, resolved once in `build_pipeline_config` so the feature-cache fingerprint stays correct if the global ever changes); RB/WR/TE set to 1 (no filter). Validated full-model 8-seed on each position's **served** model (Δ = MAE@6 − MAE@1, + = relax helps): RB LGBM `would_filter` +0.175±0.021 / `kept` +0.036; WR LGBM +0.209±0.027 / +0.053; TE attn +0.214±0.122 / −0.005 (flat) — cold-start improves, established not hurt, overall MAE slightly better. K/DST inert (no <6-game team/kicker seasons; K also floors its own `min_games` in `k/data.py`), left at the global 6. QB **excluded** — mixed (served Ridge benefits, but attention `kept` −0.404±0.158); see [TODO.md](../../TODO.md) Open *"[OPEN] QB min-games relaxation"*.
- **Lesson:** a split's own preprocessing can manufacture the very train→test covariate shift its CI guard then measures — audit train-only filters against the *unfiltered* test population, by subgroup. And the single-seed deterministic proxy mis-ranked QB ("ship it"); the 8-seed full-model run caught the attention regression — judge a population change on the served model across seeds, not a proxy.
