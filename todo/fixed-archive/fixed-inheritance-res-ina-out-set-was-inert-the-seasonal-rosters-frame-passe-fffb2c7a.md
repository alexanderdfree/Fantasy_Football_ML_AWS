### [FIXED] Inheritance RES/INA out-set was inert — the seasonal rosters frame passed the column guard
- **File(s):** [../src/data/nfl_source.py](../../src/data/nfl_source.py) (`rosters_weekly()`), [../.github/workflows/refresh-splits.yml](../../.github/workflows/refresh-splits.yml) (heredoc → `rosters_weekly` + hard weekly-granularity assert), [../src/features/engineer.py](../../src/features/engineer.py) (loud warnings on missing columns / season-granular shape), tests in [../tests/test_engineer.py](../../tests/test_engineer.py) + [../tests/test_nfl_source.py](../../tests/test_nfl_source.py). PR #1133; shipped-inert in #1108/#1129.
- **What:** The #1106 vacancy out-set (rosters `status ∈ {RES, INA}`) was wired to `nfl_source.rosters` = nflreadpy `load_rosters` — the **seasonal** dataset (~1 row per player-season). That frame *also* carries `week`/`status` columns, so `_build_inheritance_features`' column-presence guard passed and the block ran — against data that cannot describe per-week absences. Production splits had `inherited_opportunity = 0` on every #1106 case row (Gainwell wk4, Mason wk3/4, Haskins wk6/7, Demercado wk4/10) while unit tests stayed green (synthetic fixtures were weekly-shaped) and the INA merge's benchmark delta read **exactly +0.000 on Ridge for all positions** — initially misread as sub-rounding instead of the no-op tell. Positive control: the same function fed weekly-granular rosters gives Gainwell wk4 → 0.61 (Warren's wk1-3 snap mean).
- **Fix:** New `nfl_source.rosters_weekly()` (`load_rosters_weekly` + the `gsis_id→player_id` alias); the refresh-splits heredoc uses it and **asserts ≥5 distinct weeks/season** (fail loud, never inert); the engineer guard now `logger.warning`s on missing columns AND on a season-granular shape. Post-fix splits: 370 of the 2025 test rows carry the signal (Gainwell 0.61, Vidal 1.16/0.74, Carter 0.98); skill-position Ridge moved at the activation merge (the data-identity tell). Cohort verdict: invisible-vacancy bias gap −0.81 → −0.54 (33% closed; #1106 closing comment).
- **Lesson:** A column-presence guard cannot distinguish datasets that share a schema — verify the **granularity** of the frame, not just its columns, and never let a data-dependent feature path skip silently (warn or assert). On the read side: a deterministic-model delta of exactly 0.000 after a data-path merge is an activation failure until proven otherwise, not rounding. And green units prove the function, not the production invocation — the synthetic fixture matched the intended shape, not the shipped one.
