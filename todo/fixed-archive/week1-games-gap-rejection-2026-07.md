- **Result — measurement (baseline arms; bias = pred−actual, mean over seeds):** the week-1 under-projection is **QB- and K-specific, NOT RB/WR/TE** — refuting the entry's "expect QB-like for RB/WR/TE". **QB** (wk1 actual 16.15 vs rest 12.88, n=34): every model 0.4–1.8 FP more negative at wk1 than rest (NN −2.8 vs −1.0; Ridge −0.10 vs +1.08; LGBM −0.37 vs +0.69; attn −0.39 vs +0.02). **K — new finding** (wk1 actual 9.34 vs rest 8.72, n=31, both seeds): ALL four models more negative at wk1 (relative −0.25 to −0.77) *despite* K's cross-season rolling windows. **RB and TE lean OVER-projection at wk1** (wk1 actuals are *lower* than rest: RB 6.25 vs 7.39, TE 4.88 vs 5.65; RB attn +0.56 / LGBM +0.62 wk1 vs −0.56 / +0.02 rest; TE Ridge +0.24 vs −0.45, LGBM +0.35 vs −0.15). **WR** ≈ flat/mixed (NN mildly under, Ridge mildly over, wk1 actual 6.53 ≈ rest 6.67).
- **Result — arms:** none ships. **QB:** both feature arms destabilize the attention NN — overall MAE +5.6% (career_gap) / +6.6% (itt_empty), one seed's wk1 bias blowing out to −6.4 — and fail the #1137 passing-yards guard (NN +1.6–2.0%, LGBM +1.0–1.1%); the known "QB static features overfit/destabilize" pattern. **RB itt_empty** and **WR career_gap/itt_empty** pass the week1 gate (≥3/4 models improved on ≥2/3 seeds; e.g. RB attn +0.56→+0.31) but fail `returning`, and the wk1 defect they would fix doesn't exist at RB/WR anyway. **RB rb_returning** fails its own target cohort (returning Ridge −0.54→−0.62) — consistent with the original r=0.934-with-`days_rest` drop.
- **Lesson:** (1) **Measure the cohort before building the fix** — the recorded expectation was wrong in *direction* for RB/TE; a shipped blanket week-1 calibration would have worsened them. (2) A *conditioning* scalar can hurt like carried form: the gap feature reproduced #1137's QB passing-yards regression without carrying any values. (3) A "toward-0" gate is only meaningful when the target cohort is actually biased — the RB/WR week1 "passes" were mostly noise shrinkage around an already-small bias. (4) The baseline-arm-as-measurement pattern (custom `metric_fn` + identity variant) delivers the cohort measurement and the A/B from one fleet dispatch — reuse it. Remaining live thread: a **QB/K-scoped** conditional calibration — K is the cleaner first target (consistent under-projection, no destabilization, previously assumed flat); any future QB attempt must carry an attention-MAE non-regression guard.
