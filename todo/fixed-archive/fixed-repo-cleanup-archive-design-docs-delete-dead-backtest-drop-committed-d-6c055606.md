- **Lesson:** `.gitignore` does nothing for files already in the index — patterns added after a commit silently fail to ignore the existing tracked file. When adding a gitignore rule, also `git rm --cached` any matching tracked files or the rule is half-broken. Companion lesson: docs that say "folded into the ADR" still cost reader attention if they sit next to the ADR — explicitly archive them (move + README pointer) rather than hoping the "historical" header is enough. Companion lesson for module duplication: two files exporting the same function name are a smell, but the actual test is "who imports each one." A module imported by exactly one test that tests *itself* is dead code wearing a coverage badge.
