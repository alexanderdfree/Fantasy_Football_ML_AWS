### [FIXED] Pre-PR B2 benchmark gate: mtime freshness + hand-maintained path map → content fingerprints + scope_positions single-sourcing
- **File(s):** [../.claude/hooks/pre-pr.sh](../../.claude/hooks/pre-pr.sh) (B2 rewrite), NEW [../src/scripts/bench_fingerprint.py](../../src/scripts/bench_fingerprint.py) + [../src/scripts/pre_pr_bench_check.py](../../src/scripts/pre_pr_bench_check.py), [../src/scripts/scope_positions.py](../../src/scripts/scope_positions.py) (`compute_benchmark_scope`), the three benchmark writers ([../src/benchmarking/benchmark.py](../../src/benchmarking/benchmark.py), [../src/benchmarking/parallel_train.py](../../src/benchmarking/parallel_train.py), [../src/batch/benchmark.py](../../src/batch/benchmark.py)) now record `code_fingerprints`.
- **What:** B2's freshness proxy was `benchmark/output mtime > max mtime over ALL pipeline files`: the recorded `git_hash` was never consulted, so evidence from *different* code passed while evidence for the *exact current* code broke the moment `rebase`/`stash pop`/`checkout` bumped any pipeline file's mtime (the documented order-operations-or-`touch` gotcha; also forced re-runs after every rebase in tier PRs). Its path→position map was a hand-maintained 5-basename case-statement that disagreed with the canonical `scope_positions.py` (missed `src/{pos}/__init__.py`/diagnostic CLIs/nested shared paths/`src/__init__.py`). The entire B2 body had zero tests. A missed third history writer (`parallel_train.py` — the default CUDA-box path) would have made most local runs legacy forever.
- **Fix:** Evidence is now **content identity**: writers record per-position `code_fingerprints` (sha256 over the sorted (path, git-blob-sha) manifest of `src/{pos}/**` + the shared set; worktree-hashed at train time), and the gate matches them against the branch **HEAD** fingerprint — worktree/machine/CI portable, immune to mtime churn. Scoping single-sourced in `compute_benchmark_scope` (per-position prefix rule; shared arm keeps the documented ≥1-position policy; `src/batch/**`+`requirements.txt` exempt-but-reported). Legacy mtime tier self-retires per position at its first fingerprinted run; `{pos}/outputs/models` mtime stays as bare-`run_pipeline` evidence (with a nudge). New AST-equivalence tier skips provably inert comment/docstring/format-only files. B2 brain moved to unit-tested stdlib Python with a PASS/FAIL protocol; evaluator crash = loud fail-open (the #894 wedge-class rule). ~50 unit tests incl. subprocess hook characterization.
- **Lesson:** A freshness gate should compare *identity* (content hash), not *time* — mtime proxies conflate "newer" with "about this code" and break under every git operation that re-materializes files. And when two path→scope mappings exist (hook case-statement vs `scope_positions`), they WILL drift — collapse onto the importable canonical one and pin the parity with contract tests. Provenance fields nobody reads (`git_hash`) rot: record what the consumer actually checks.
