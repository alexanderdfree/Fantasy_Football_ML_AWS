### [FIXED] MPS tune workers replayed identical TPE startup draws (fresh fixed-seed sampler per loop iteration)
- **File(s):** [../src/tuning/tune_nn.py](../../src/tuning/tune_nn.py) (`_worker_sampler_seed` + `_mps_worker_entry` loop); regression test in [../tests/tuning/test_tune_nn.py](../../tests/tuning/test_tune_nn.py).
- **What:** `_mps_worker_entry`'s one-trial-per-iteration loop re-created the study AND a fresh `TPESampler(seed=42 + worker_idx)` every iteration. Re-creating study+sampler per trial is the standard distributed-Optuna pattern (TPE must see fresh history) — but a freshly-instantiated sampler with a **fixed** seed replays the identical random draw during TPE's startup phase (`n_startup_trials=10`), so each worker re-trained its own identical config until 10 trials completed. Confirmed on AWS Batch CloudWatch (2026-06-10 RB tune, `n_jobs=4`): trials 0/5/9 bit-identical params + identical objective (60.019813537597656; pipeline seed fixed at 42, so duplicates carry zero new information), trials 2/6 another pair — ~5 distinct configs in 10 trials, roughly half the GPU time wasted. The thread backend was unaffected (one sampler instance shared across trials advances its RNG state).
- **Fix:** Vary the sampler seed per loop iteration via `_worker_sampler_seed(worker_idx, iteration) = 42 + worker_idx + 1009 * iteration` (1009 prime ≫ any plausible `n_jobs`, so worker seed streams never collide). Cross-run search-path reproducibility was already lost to concurrent trial-completion timing, so nothing real is given up. Regression test drives two loop iterations through the real `_create_or_load_study` + `_sample_overrides` path and asserts the startup draws differ (fails bit-identically pre-fix).
- **Lesson:** In a re-create-per-trial distributed-Optuna loop, a fixed sampler seed resets the RNG to the same point every trial — the seed must vary per iteration (or be `None`). Duplicate-config detection: scan tuning logs for bit-identical params/objective values across trials; with a fixed pipeline seed, a repeated objective value to full float precision is the tell.
