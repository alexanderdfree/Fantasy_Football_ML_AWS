### [FIXED] Leaked `model-refresh-poll` daemon polluted sibling tests' global `boto3.client` mocks (CI flake)
- **File(s):** [src/shared/model_sync.py](../../src/shared/model_sync.py) (`start_refresh_poller` gained an optional `stop_event` graceful-shutdown hook), [tests/shared/test_model_sync_refresh.py](../../tests/shared/test_model_sync_refresh.py) (both poller tests stop+join the thread before teardown) — PR #446.
- **What:** `test_local_benchmark_sync.py::test_maybe_upload_to_s3_region_fallback` flaked on `main` with `boto3.client ... Called 7 times` (expected once). The root cause was in a *different* file: `test_model_sync_refresh.py` started `start_refresh_poller(interval_s=0)` — an unbounded daemon with no shutdown API ("relies on daemon=True for process exit") — and never stopped it. After `monkeypatch` restored the real `refresh_position`, the still-spinning daemon called the real `boto3.client("s3")` once per position (`[refresh] {pos} unexpected: NoCredentialsError`) and those calls landed inside any later same-xdist-worker test that patched `boto3.client` globally, inflating its call count nondeterministically.
- **Fix:** Added an optional `stop_event` to `start_refresh_poller` (interruptible sleep + loop guard; production callers omit it, so the `while True` + `daemon=True` path is byte-identical). Both poller tests now pass a `stop_event` and `stop.set()` + `join()` + assert-stopped in a `finally`, killing the daemon *before* monkeypatch teardown. `test_local_benchmark_sync.py` was left unchanged — its `assert_called_once` is correct under proper isolation.
- **Lesson:** A leaked daemon thread that calls a globally-patchable function (`boto3.client`) is a cross-test time bomb under pytest-xdist — the victim is whichever test happens to share the worker and patch that global, so the failure points at the wrong file. Fix the leak at the source (give long-running daemons a stop hook + join them in tests), not the symptom assertion. Reproduce deterministically in one process: `pytest <poller_test> <victim_test> -n0 -p no:randomly`.
