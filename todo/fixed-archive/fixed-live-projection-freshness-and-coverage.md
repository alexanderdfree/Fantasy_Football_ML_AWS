### [FIXED] Live projections hid source outages, retained stale views and omitted current player metadata

- **File(s):** `src/serving/espn_live.py`, `live_qbr.py`, `upcoming_status.py`, `upcoming_week.py`, `roster_meta.py`, `routes.py`, NextWeek frontend/controller and focused regression tests (PR pending).
- **What:** Failed injury requests returned empty maps and became healthy defaults; a partial team-roster outage could publish an incomplete slate. Verified offseason never reached S3, old artifacts remained apparently current, and the browser's module cache never revalidated. Fixed-year roster metadata could not match 2026 rows. Supplementary-source availability meant merely a nonempty file or one matched opportunity row. The live comparison adapter repeatedly requested unverified 2026 NFL.com archive files.
- **Fix:** Validate a single current-season injury response, its timestamp/identities/statuses and scheduled-team coverage; use it for both exclusion and status. Reject incomplete team rosters and missing position predictions before publication. Publish offseason state through the same checked S3 path. Compute freshness from source/input/generation timestamps at read time and revalidate browser data with retries and explicit last-good warnings. Inject current roster/schedule metadata with season-matched ESPN DOB/debut/experience fallback. Report per-source observed/expected coverage, retaining trained missing-data semantics. Recover missing QBR from the identical upstream ESPN statistic with game/player validation. Keep the verified NFL.com archive available historically, with an explicit operator opt-in for reverified current coverage.
- **Evidence:** The September 10 source replay recovered Drew Lock's Total QBR 78.6 / points-added 3.0 and Drake Maye's 56.4 / 0.2 from the correct completed game; the maintained parquet had mislabeled 540 prior-year rows. All 488 player rows gained age/rookie metadata; 30 DST units correctly remained null. Regression tests reproduce injury outages, wrong/stale/partial source responses, old artifact redownloads, offseason upload failure and browser stale → error → fresh recovery. Full current-season snap counts and expected opportunity were still unpublished upstream; these are disclosed external source limits, not replaced with guessed observations.
- **Lesson:** Successful HTTP, nonempty data, fresh downloads and a recent generation timestamp are separate from valid, complete and current source observations. Preserve source provenance through every cache and treat provider outages distinctly from healthy players or zero usage. Check the actual upstream feed before declaring a missing release irrecoverable.
