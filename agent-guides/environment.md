# Local environment and validation gates

Read only the sections relevant to the task. [AGENTS.md](../AGENTS.md) supplies the shared entrypoint; current code/config and linked decisions supply operational state. Dated measurements describe their recorded regime, not a promise about today.

### Environment (macOS / worktree / venv / pytest)
- Remote Claude sessions use the [SessionStart bootstrap](providers/claude.md#hooks). A plain `uv venv` does not seed pip: automated installs must name the venv interpreter (`uv pip --python <venv>/bin/python`) or deliberately seed pip. Do not rely on activation to make a bare `pip` target the intended environment.
- **macOS has no `timeout`, and `cmd | tail` makes the exit code tail's (0)** — redirect to a file and verify the artifact, not the reported code.
- **Avoid accidental environment mutation.** Use the canonical requirements with an explicitly selected interpreter, or `uv run --with` for an isolated tool. If an ad-hoc install changes the environment unexpectedly, verify which environment was targeted before reinstalling; do not treat the old incident as a guarantee that every `uv pip install` wipes a venv.
- **Don't symlink the `.venv` in a worktree** (site-packages resolves wrong) — use an absolute python path. Data symlinks ARE fine.
- **A worktree does NOT symlink `.venv`, so a hook/tool resolving a venv only from `$PROJECT_DIR/.venv` silently no-ops in a fresh worktree** — also probe the MAIN worktree's `.venv` (first `git worktree list --porcelain` entry), in both the `bin/` and Windows `Scripts/` layouts. [.claude/hooks/ruff-format.sh](../.claude/hooks/ruff-format.sh) + [.codex/hooks/ruff-format.sh](../.codex/hooks/ruff-format.sh) do this (#1232/#1241); mirror it in any new venv-resolving hook.
- **Fresh worktree: symlink the parent's `data/{splits,raw}`** when local paths are absent or confirmed empty, instead of a slow first pull. Inspect existing paths first; do not delete populated local data to make room for a symlink. **Claude's `SessionStart` hook now does this automatically** (`claude_link_worktree_data`, [.claude/hooks/lib.sh](../.claude/hooks/lib.sh) → [.claude/hooks/session-start.sh](../.claude/hooks/session-start.sh)); the manual command is the fallback for Codex / non-hook contexts (Codex covers it in [scripts/codex-fresh-worktree.sh](../scripts/codex-fresh-worktree.sh)).
- **Match the interpreter/tools used by the pre-PR gate.** [The resolver](../.claude/hooks/pre-pr.sh) checks worktree `.venv`, then main-worktree `.venv`, then PATH (Unix and Windows layouts). An activated base environment does not override a discovered venv. Verify the selected environment against [SETUP.md](../SETUP.md#install) before diagnosing dependency differences.
- **Symlinked parent `data/splits` lag main's feature whitelist** → pipeline fails loud (`KeyError: N whitelisted cols missing`); rebuild splits locally, or verify non-model code with synthetic tests — don't diagnose via column-diff (pipeline-time features are absent by design) (#656).
- **The pre-PR benchmark gate accepts evidence by content fingerprint** (`code_fingerprints` in `benchmark_history/*.json` vs the branch HEAD — see `src/scripts/bench_fingerprint.py`), so `git stash pop`/`rebase`/`checkout --` mtime churn no longer breaks it. New gotchas: any post-benchmark edit to a gated file needs a re-run (~1–2 min/position warm) — the AST-inert tier only excuses a file whose ENTIRE base..HEAD diff is comments/docstrings/formatting (a comment added on top of a substantive change still shifts the fingerprint), and `git add` new pipeline files BEFORE benchmarking (untracked files are outside the fingerprint, so the evidence won't cover them once committed).
- **Passing alone and failing in a suite does not prove an xdist race.** Reproduce a suspected polluter file followed by the victim in one process before blaming concurrency or copying real data. The [resolved ordering-pollution incident](../todo/fixed-archive/fixed-xdist-race-unit-flake-from-import-copies-of-load-schedules-bypassed-th-c98863be.md) records the cause and fix. [Root conftest](../conftest.py) isolates loader writes; [test fixtures](../tests/conftest.py) stub missing schedules and flag writes to real `data/raw`. A fixture/cache leak needs a routing fix, not a retry-as-flake.
- **Stalled pytest with no `=== passed ===` footer** → re-run the suspect file in isolation FAST; don't reverse-engineer the dots.
- **Handoff/plan docs go at repo root or the tracked `todo/` folder** (linked from TODO.md, `[docs-only]`), NOT `.claude/plans/` (gitignored) or `docs/` (fires deploy + public wiki).
- **Splitting/renaming a tracked doc can break a test/CI allowlist that names its path as a string literal** — grep the OLD path across `tests/`/`.github/`/`.claude/`, extend the allowlist + repoint refs in the same PR, `git add` the new file before the coupled test (#661).
